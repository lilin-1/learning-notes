# Given a compute budget, how large should the model be and how much data should it see?

By the [[scaling laws]]: training takes about $6ND$ operations, where $N$ is the number of parameters and $D$ the number of tokens. For a given budget, the configuration with the lowest loss grows $N$ and $D$ in equal proportion; by the Chinchilla results, that comes to about 20 tokens per parameter.

But this counts only training. A trained model serves a great many requests, and the cost of inference grows with the parameters, so in practice smaller models are often trained on more data, spending more compute on training in exchange for cheaper inference. A [[mixture of experts]] takes another route: its total parameters are large but its [[active parameters]] small, and computation grows only with the latter.

Example: For a budget of $10^{24}$ floating-point operations, setting $D = 20N$ gives $6N \times 20N = 10^{24}$, so $N \approx 9.1 \times 10^{10}$: about 91 billion parameters and 1.8 trillion tokens.
