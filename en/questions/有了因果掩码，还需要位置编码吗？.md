# With a causal mask, is a positional encoding still needed?

Strictly speaking it is not required, but nearly every model still adds one, most often a [[rotary position embedding]].

[[self-attention|Self-attention]] without a mask is equivariant to permutations of its input: when the tokens are shuffled, the outputs merely shuffle along with them, so the model cannot tell word order, which is why [[BERT]] must have a [[positional encoding]]. A [[causal mask]] breaks this symmetry: position $i$ sees only the first $i$ tokens and the first position sees only itself, from which the model can infer positions and, layer upon layer, word order. Studies have found that [[decoder]]-only [[language model|language models]] with no positional encoding at all can come close to those with one.

Still, this positional information must be derived by the network itself and is less direct; rotary position embedding writes relative distance into the dot product of queries and keys, which makes training easier and the context easier to extend.

Example: “Dog bites man” and “man bites dog” show the same tokens at the last position. But the first position sees only “dog” in one and only “man” in the other, which is enough for a masked model to tell the two apart.
