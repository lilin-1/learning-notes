# What computations does a token go through from input to output?

Taking a [[language model]] such as [[GPT]] as an example, there are five: tokenization, embedding, layer-by-layer transformation, scoring and selection.

Text is first split into [[token|tokens]] by [[byte pair encoding]]; each token is looked up in the [[embedding]] table to get a vector, to which a [[positional encoding]] is added. The vectors then pass through $N$ identical layers. Each layer first applies [[multi-head attention|multi-head]] [[self-attention]] with a [[causal mask]], gathering information from the preceding text, and then transforms each position with a [[feedforward network]]; both sublayers are wrapped in a [[residual connection]] and [[layer normalization]].

The output of the last layer is multiplied by a matrix, giving [[logits]] for every token in the vocabulary. [[softmax|Softmax]] turns the logits into a distribution over the next token, from which one is chosen by [[greedy decoding]] or [[temperature sampling]].

Example: In the smallest GPT-2, a token's index first becomes a 768-dimensional vector and is still 768-dimensional after 12 layers. Finally it is mapped to 50257 logits, one for each token in the vocabulary.
