# What exactly does the attention mechanism compute?

A weighted average: the query is compared with each key, the comparisons are turned into weights by [[softmax]], and the corresponding values are summed with those weights. The [[attention mechanism]] thereby lets each position gather information from other positions as needed, with weights that depend on the input rather than being fixed parameters.

In [[self-attention]] the queries, keys and values all come from the same sequence, which is how each token sees its context; [[scaled dot-product attention]] compares by dot product and divides by $\sqrt{d_k}$ to control the scale.

Example: The query $q = (2, 0)$ has dot products $(2, 0, -2)$ with the three keys $(1, 0)$, $(0, 1)$ and $(-1, 0)$, giving weights of about $(0.87, 0.12, 0.02)$. If the three values are $1, 2, 3$, the output is about $1.15$, drawn almost entirely from the first value.
