# What instructions can a GPU execute?

There are two levels. A [[kernel]] is first compiled into [[PTX]], a stable virtual instruction set that describes the behavior of a single thread and is common to all GPU generations. PTX is then assembled into [[SASS]], the machine instructions a particular generation executes, each carried out by the 32 threads of a [[warp]] together.

The machine instructions fall into four classes. Arithmetic instructions perform integer and floating-point operations, such as the single-precision multiply–add `FFMA`; the matrix multiply–accumulate `HMMA` goes to the [[Tensor Core|Tensor Cores]] and completes a small matrix multiplication in one instruction. Memory instructions move data between the levels of the [[memory hierarchy]], such as `LDG` and `STG` for GPU memory and `LDS` and `STS` for shared memory. Synchronization instructions coordinate threads: `BAR` makes the threads of a block wait for one another, and `SHFL` exchanges registers within a warp. Control instructions include the branch `BRA`, the terminating `EXIT`, and `S2R`, which reads the thread index.

These are instructions, not commands. Through the [[command buffer]] the CPU issues commands such as “launch a kernel” or “copy memory”; instructions are the content of the kernel itself.

Example: The body of the elementwise addition $z_i = x_i + y_i$ is two `ld.global.f32`, one `add.f32` and one `st.global.f32` in PTX, which become two `LDG`, one `FADD` and one `STG` in SASS.
