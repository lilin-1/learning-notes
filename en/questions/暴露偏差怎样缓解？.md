# How can exposure bias be mitigated?

By letting the model see its own outputs during training. [[exposure bias|Exposure bias]] stems from [[teacher forcing]]: in training the context is all real data, but in generation the model writes it itself. The remedies all try to narrow this gap.

[[scheduled sampling|Scheduled sampling]] changes the input, not the objective: during training it gradually replaces the true context with the model's own predictions, using almost only true tokens at first and mostly predictions later. [[sequence-level training|Sequence-level training]] changes the objective: the model generates whole sentences, rewards or risks are computed from sentence-level evaluations, and the model is updated, so that it trains on its own outputs. Post-training of today's large models has the same effect: [[reinforcement learning from human feedback|RLHF]] and [[GRPO]] both compute rewards on responses the model samples itself.

Each method has a cost. The objective of scheduled sampling is theoretically improper, and applied to Transformers it loses parallelism; sequence-level training is slow, has high variance, and must start from cross-entropy training. The impact of exposure bias itself is also debated: one study found the distortion in open-ended generation limited, with the model able to recover by itself.

Example: On image captioning, scheduled sampling raised BLEU-4 from 28.8 to 30.6, whereas always using the model's own predictions lowered it to 11.2.
