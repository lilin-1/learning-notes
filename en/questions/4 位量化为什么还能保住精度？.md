# Why can 4-bit quantization still preserve accuracy?

Because the error can be steered to where it matters little instead of being spread evenly. Rounding each weight to the nearest grid point on its own lets the [[quantization]] error accumulate in the output; several methods each reduce it from one angle.

[[GPTQ]] quantizes column by column, adjusting the later columns after each one to offset its error. [[AWQ]] observes that a few input channels have especially large activations and that the weights multiplied by them matter most, so it enlarges those weights and shrinks the inputs before quantization, leaving the product unchanged and the error smaller. [[SmoothQuant]] migrates outliers from the activations to the weights, so that the activations can be quantized too.

The granularity of scaling matters as much. [[microscaling formats|Microscaling formats]] let every 32 or even 16 numbers share a scale factor, so each block takes grid points suited to its own range; [[FP8]] is likewise always used with fine-grained scaling.

Example: OPT-175B in 16 bits takes about 350 GB and needs 5 GPUs of 80 GB. Quantized to 3 bits by GPTQ, it takes about 63 GB and fits on one.
