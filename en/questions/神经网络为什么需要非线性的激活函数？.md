# Why do neural networks need nonlinear activation functions?

Because without them, any number of stacked layers amounts to a single layer. Each layer of a [[neural network]] is an affine map, and a composition of affine maps is still affine, so however many layers there are, they can represent only affine functions.

Inserting an [[activation function]] between layers makes the composition no longer affine. A single hidden layer of sufficient width can then approximate any continuous function on a bounded region to arbitrary precision; the [[feedforward network]] has exactly this structure and applies a nonlinear transformation to the vector at each position.

Example: The two layers $f(x) = 3(2x + 1) - 4 = 6x - 1$ still form a straight line. With a ReLU inserted, $3\,\mathrm{ReLU}(2x + 1) - 4$ is constantly $-4$ for $x < -1/2$ and equals $6x - 1$ elsewhere, a broken line.
