A parameterized function $f_\theta$ composed of layers. The most basic layer is $x \mapsto \phi(xW + b)$, where $W$ and $b$ are parameters and $\phi$ is an [[activation function]]. The parameters $\theta$ are found by approximately minimizing a [[loss function]] on training data, usually with [[gradient descent]], the gradients being computed by [[backpropagation]].

Example: XOR takes the values $0, 1, 1, 0$ at $(0, 0)$, $(0, 1)$, $(1, 0)$, $(1, 1)$. No affine function takes these values at these four points, but the two-layer network $f(x) = \mathrm{ReLU}(x_1 + x_2) - 2\,\mathrm{ReLU}(x_1 + x_2 - 1)$ does.
