Low-bit formats in which a small block of elements shares one scale factor, abbreviated MX. Each block of 32 elements shares an 8-bit scale factor that can only be an integer power of 2; the elements themselves may be 8-, 6- or 4-bit floating-point numbers. The 4-bit element format E2M1 can represent only $0$, $\pm 0.5$, $\pm 1$, $\pm 1.5$, $\pm 2$, $\pm 3$, $\pm 4$ and $\pm 6$.

Note: The smaller the block, the better the scale factor fits the block's range of values, so that even 4 bits preserve accuracy; the price is the extra bits of the scale factors. NVIDIA Blackwell's NVFP4 shrinks the block to 16 elements, each block sharing an [[FP8]] scale factor, with one more 32-bit factor for the whole tensor. Such formats are supported directly by the [[Tensor Core|Tensor Cores]], so 4-bit matrix multiplication need not first expand to 16 bits.

Example: An MXFP4 block is 32 elements of 4 bits plus an 8-bit scale factor, $32 \times 4 + 8 = 136$ bits, an average of 4.25 bits per element. NVFP4 adds 8 bits per 16 elements, an average of $4 + 8 / 16 = 4.5$ bits.
