A form of parallelism in which every GPU holds a full copy of the model and processes different data of the batch, after which the gradients are averaged and all copies update together. The averaging is one all-reduce: with the common ring algorithm, each GPU sends and receives about $2(N - 1)/N$ times the size of the gradients, which barely grows with the number of GPUs $N$.

Note: It is the simplest form and scales the best, but every GPU must hold the full model, gradients and optimizer state, which no longer fit once the model is large. Training large models therefore combines it with [[tensor parallelism]] and [[pipeline parallelism]], or shards the state that each GPU would otherwise duplicate.

Example: With $N = 8$, each GPU sends and receives about $2 \times 7 / 8 = 1.75$ times the size of the gradients. For a 7-billion-parameter model with 16-bit gradients of about 14 GB, each GPU moves about 24.5 GB per step.
