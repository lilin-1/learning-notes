[[multi-head attention|Multi-head attention]] that first compresses each token's keys and values into one low-dimensional vector and caches only that vector, abbreviated MLA and introduced by DeepSeek. The token representation $h_t$ is projected to $c_t = W^{D} h_t$; when needed, up-projections recover each head's keys and values: $k_t = W^{UK} c_t$ and $v_t = W^{UV} c_t$. [[rotary position embedding|Rotary position embedding]] is incompatible with this compression, so a small vector shared by all heads carries position separately.

Note: At inference, the up-projections can be merged into other matrices: $W^{UK}$ into the query projection and $W^{UV}$ into the output projection, so attention is computed directly on the compressed vectors. Unlike [[grouped-query attention]], it does not make several heads share one set of keys and values; all heads share one compressed representation, from which each head still extracts keys and values of its own. Position has to be stored separately because a rotation sandwiched between two matrices would prevent the up-projection from being merged.

Example: DeepSeek-V3 has 128 heads per layer of 128 dimensions each, a compression dimension of 512 and a 64-dimensional key carrying position. Each token caches only $512 + 64 = 576$ numbers per layer; multi-head attention of the same shape would cache $2 \times 128 \times 128 = 32768$, about 57 times as many.

Paper: [DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model](https://arxiv.org/abs/2405.04434) (DeepSeek-AI, 2024)
