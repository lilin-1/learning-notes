[[self-attention|Self-attention]] in which each position attends only to the $w$ positions before it, $w$ being the window size. The computation is $n \times w$, growing linearly with the length $n$. The [[KV cache]] need hold only the latest $w$ positions and can be circular: the keys and values of position $i$ go into slot $i \bmod w$, overwriting old values that have left the window.

Note: Information outside the window is not entirely lost. Each layer gathers information from the previous $w$ positions, so after $L$ layers the top layer can in theory see, indirectly, as far as $L \times w$ positions back. The price is that distant information passes through many layers rather than being attended to directly, so some models use sliding windows only in some layers and keep global attention in the rest.

Example: The first version of Mistral 7B takes $w = 4096$ with 32 layers, a theoretical reach of about $32 \times 4096 = 131072$ positions. For a sequence of 32768, the KV cache need hold only 4096 positions, $1/8$ of the full cache.
