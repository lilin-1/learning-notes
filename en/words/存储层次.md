The levels of storage on a [[graphics processing unit|GPU]], from fast and small to slow and large. Registers are private to each thread; shared memory is shared by the threads of a thread block. Both sit inside the [[streaming multiprocessor]] and are the fastest to access. The L2 cache is also on the chip and is shared by all SMs. GPU memory (HBM) lies off the chip, with the largest capacity and the slowest access.

Note: Optimizing a kernel is largely a matter of arranging how data flows between these levels: a number read from GPU memory should be used as many times as possible in registers and shared memory before it is written back. Together these two hold only tens of megabytes across the whole GPU, not enough for a large matrix, so data is cut into small tiles and processed one tile at a time.

Example: Each SM of the A100 has 256 KB of registers and up to 164 KB of shared memory, about 44 MB over its 108 SMs. The L2 cache is 40 MB, and GPU memory is 80 GB with a bandwidth of about 2 TB/s. A $128 \times 128$ tile of 16-bit numbers takes 32 KB, so one SM's shared memory holds at most 5 of them.
