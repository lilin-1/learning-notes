A form of parallelism that splits the weight matrices of each layer across several GPUs, which compute simultaneously. [[multi-head attention|Multi-head attention]] is split by heads; the first matrix of the [[feedforward network]] is split by columns and the second by rows. Each sublayer then needs only one all-reduce at its end, which sums the partial results of all the GPUs.

Note: It lowers both the memory per GPU and the latency per token, since the computation of every layer is shared. The price is communication: one all-reduce per sublayer, whose volume grows with the number of layers and the batch size, so it suits only GPUs with very high interconnect bandwidth, usually within a single machine.

Example: A feedforward network with $d = 4096$ and inner dimension 16384 is split across 4 GPUs. Each GPU stores a $4096 \times 4096$ slice of $W_1$ and a $4096 \times 4096$ slice of $W_2$, only $1/4$ of all the weights.

Paper: [Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism](https://arxiv.org/abs/1909.08053) (Shoeybi et al., 2019)
