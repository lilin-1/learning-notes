A structure, abbreviated MoE, that replaces the [[feedforward network]] of a [[Transformer]] with $E$ parallel feedforward networks $f_1, \dots, f_E$, called experts, and lets a router select only $k$ of them for each [[token]]. The router is a linear layer $W_r \in \mathbb{R}^{d \times E}$: for a token representation $x$ it computes $E$ [[logits]] $s = xW_r$, picks the largest $k$, and turns them into weights $g_j$ with [[softmax]]. The output is

$$y = \sum_{j \in \mathrm{top}_k(s)} g_j\, f_j(x).$$

Experts that are not selected do no computation.

Note: The router is trained with the rest of the model; selecting the top $k$ is not differentiable, so gradients reach $W_r$ through the weights $g_j$. The structure decouples parameter count from computation: parameters grow with $E$, while the computation per token grows only with $k$. When routing is uneven, some experts are overloaded while others sit idle, so training usually adds a loss that encourages balanced load.

Example: Let $E = 4$, $k = 2$, and let a token's logits be $(0.5, 2.0, 1.0, -1.0)$. Experts 2 and 3 are selected, with weights $\mathrm{softmax}(2, 1) \approx (0.73, 0.27)$, so $y = 0.73\,f_2(x) + 0.27\,f_3(x)$.
