Feeding a [[decoder]], when training an autoregressive model, the true preceding tokens at every position rather than the model's own predictions. The target sequence shifted right by one serves as the input: the input is a start token followed by $y_1, \dots, y_{m-1}$, and position $t$ must predict $y_t$. Together with the [[causal mask]], the predictions and the [[cross-entropy]] loss at all positions can be computed at once in a single forward pass.

Note: It makes training parallel and also more stable: if the model's own predictions served as context, early errors would propagate and later positions would never learn from the correct context. The price is a mismatch between training and generation: in generation the model sees only its own outputs, yet in training it never saw what follows its own mistakes. This mismatch is called exposure bias.

Example: The German target “Ich liebe dich” has 4 tokens with the end token. The decoder's input is (start token, Ich, liebe, dich), and the positions must predict (Ich, liebe, dich, end token) in turn. Even if the model mispredicts liebe at position 2, the input at position 3 is still the correct liebe.
