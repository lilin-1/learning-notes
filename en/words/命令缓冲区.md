The memory through which the CPU gives commands to the [[graphics processing unit|GPU]]. The [[GPU driver|user-mode driver]] writes commands into it one after another; each command consists of a method number and a data word, such as “copy a range of memory”, “launch a [[kernel]]” or “write a semaphore”. After writing a segment, the driver records its address and length in a ring buffer, advances the tail pointer and writes the channel number to a doorbell register. The GPU then fetches the commands by DMA and hands them to the compute engine or a copy engine.

Note: Commands and instructions are different things. Commands are written by the CPU for the GPU's front end and say which job to do, and a kernel needs only one launch command; instructions are the kernel's machine code, executed by each of thousands of threads. The queue lets the two sides work asynchronously: the CPU returns as soon as it has written, the GPU takes commands in order, and each side learns the other's progress through semaphores the GPU writes back.

Example: NVIDIA's published Ampere manuals call this memory the pushbuffer and the ring buffer the GPFIFO.
