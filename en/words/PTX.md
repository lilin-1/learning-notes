The virtual instruction set that NVIDIA defines for its [[graphics processing unit|GPUs]]. A compiler first translates a [[kernel]] into PTX, which the assembler ptxas or the driver then translates into the machine instructions of a particular GPU generation. PTX describes the behavior of a single thread: it may use any number of registers, its memory instructions name an address space such as `.global` or `.shared`, and thread and block indices are read from special registers such as `%tid` and `%ctaid`.

Note: The extra layer of a virtual instruction set exists for compatibility across generations. Each GPU generation has different machine instructions, but PTX stays stable. When a program carries only PTX, the driver compiles it just in time for the current GPU at first run, so old programs run on new GPUs. The price is compilation time, and PTX does not show the final instruction layout, so tuning still requires looking at the machine instructions.

Example: The core of an elementwise addition in PTX is `mad.lo.s32 %r4, %r1, %r2, %r3;`, which computes the index from the block index, block size and thread index, two `ld.global.f32` loading $x_i$ and $y_i$, `add.f32` adding them, and `st.global.f32` writing the result.
