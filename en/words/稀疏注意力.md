A method in which each query computes attention with only a selected subset of the keys. The selection relies on a cheap score: a small computation estimates the importance of every position, and full [[attention mechanism|attention]] is computed only for the $k$ highest-scoring positions. The core computation thus grows as $nk$ instead of $n^2$.

Note: Unlike [[sliding window attention]], it selects by content, so key information far away can still be chosen. The difficulty is that the selection itself must be computed. DeepSeek-V3.2 adds a very small indexer with few heads, computed in FP8; the cost of scoring still grows as $n^2$ but is far below that of full attention. DeepSeek's other design, NSA, selects contiguous blocks, which favors [[memory coalescing]].

Example: DeepSeek-V3.2 selects 2048 key–value entries for each query. With a context of 128K, or 131072 tokens, each query looks at only about $2048 / 131072 \approx 1.6\%$ of the positions.
