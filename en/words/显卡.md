A processor designed for massively parallel computation, abbreviated GPU and originally built for rendering graphics. It devotes most of its chip area to arithmetic units: over a hundred streaming multiprocessors, each with dozens of simple cores, run the same program at once, each core on its own piece of data. The chip also holds a front end that receives commands, a unit that distributes work, the L2 cache and the memory controllers. A CPU instead uses a few complex cores to finish a single task as fast as possible.

Note: A GPU aims at throughput rather than at the latency of a single task. A read from GPU memory takes hundreds of clock cycles: a CPU shortens that wait with large caches and out-of-order execution, whereas a GPU keeps many threads ready, so that while one group waits, another computes. [[neural network|Neural network]] computation is dominated by matrix multiplication, whose many multiply–adds are independent of one another, and suits this approach well; programs full of branches and sequential dependencies run slowly on a GPU.

Example: The A100 has 108 streaming multiprocessors with 64 single-precision cores each, 6912 in all. Each core completes one multiply–add per clock cycle, that is, 2 floating-point operations; at 1.41 GHz this totals about $1.95 \times 10^{13}$ operations per second, written 19.5 TFLOPS.
