A processor designed for massively parallel computation, abbreviated GPU and originally built for rendering graphics. It devotes most of its chip area to arithmetic units, running the same program on thousands of simple cores at once, each on its own piece of data. A CPU instead uses a few complex cores to finish a single task as fast as possible. A GPU has its own high-bandwidth memory, called GPU memory.

Note: A GPU aims at throughput rather than at the latency of a single task. A read from GPU memory takes hundreds of clock cycles: a CPU shortens that wait with large caches and out-of-order execution, whereas a GPU keeps many threads ready, so that while one group waits, another computes. [[neural network|Neural network]] computation is dominated by matrix multiplication, whose many multiply–adds are independent of one another, and suits this approach well; programs full of branches and sequential dependencies run slowly on a GPU.

Example: The A100 has 6912 single-precision cores in 108 groups. Each core completes one multiply–add per clock cycle, that is, 2 floating-point operations. At 1.41 GHz, this totals $6912 \times 2 \times 1.41 \times 10^9 \approx 1.95 \times 10^{13}$ operations per second, written 19.5 TFLOPS.
