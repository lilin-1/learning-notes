The group of 32 threads in which the hardware schedules the threads of a [[kernel]]. The threads of a warp execute the same instruction at the same moment, each on its own data. When threads in a warp take different branches, the branches can only execute one after another, and while one runs, the threads not taking it sit idle; this is called branch divergence.

Note: The warp is the true unit in which a GPU issues instructions and accesses memory. Kernels should therefore keep the threads of a warp on the same path and have them access adjacent addresses; block sizes should also be multiples of 32, or the last warp has empty slots.

Example: In a warp, 16 threads enter the if branch and the other 16 the else branch, each branch taking 10 cycles. The warp executes the two branches in turn, 20 cycles in all, with only half its threads working in each. A block of 100 threads occupies 4 warps, and only 4 threads in the last one have work to do.
