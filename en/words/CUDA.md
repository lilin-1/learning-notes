The platform NVIDIA provides for general-purpose computation on [[graphics processing unit|GPUs]]. It comprises extensions to C++, the compiler nvcc, programming interfaces at two levels, runtime and driver, and a set of libraries. A program has two parts: [[host and device|host]] code that runs on the CPU, and [[kernel|kernels]] marked `__global__` that run on the GPU. nvcc translates the kernels into [[PTX]] and machine instructions and embeds them in the executable.

Note: CUDA itself provides only mechanisms; most of the performance comes from its libraries. cuBLAS performs matrix multiplication, cuDNN neural network operators such as convolution and attention, and NCCL communication among GPUs. When PyTorch runs an operator, it mostly ends up calling these libraries or kernels generated by Triton, which reach the [[GPU driver]] through CUDA's launch interface. Runtime functions start with `cuda` and driver functions with `cu`; the former is built on the latter.

Example: `cudaMalloc` allocates GPU memory, `cudaMemcpy` copies an array from the host into it, `add<<<n / 256, 256>>>(x, y, z)` launches the kernel `add` with $n / 256$ [[thread block|thread blocks]] of 256 threads each, and `cudaDeviceSynchronize` waits for completion.
