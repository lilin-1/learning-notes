A group into which the threads of a [[kernel]] are divided, also called a CTA (cooperative thread array). A launch specifies two levels of size: how many thread blocks the grid has and how many threads each block has, each arranged in one to three dimensions. Threads are told apart by their block index `blockIdx` and their index within the block `threadIdx`. The threads of a block run on the same SM, share one block of shared memory and can wait for one another at a barrier, `__syncthreads()`; different blocks cannot synchronize this way.

Note: The block is the unit in which a GPU allocates resources. A block stays resident on one SM until all its threads have finished, and the registers, shared memory and warp slots it needs are allocated in full before it starts. Whichever resource runs out first determines how many blocks an SM can hold at once. Blocks that are too small leave the SM's slots underused, and blocks that are too large are hard to fit, so 128 to 512 threads are common.

Example: On the A100 a block has at most 1024 threads. Suppose each block has 256 threads, each thread uses 64 registers and each block uses 48 KB of shared memory. Registers allow $65536 / (256 \times 64) = 4$ blocks, but shared memory only $\lfloor 164 / 48 \rfloor = 3$, so each SM holds 3 blocks, or 24 warps.
