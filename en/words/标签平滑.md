Replacing the one-hot distribution in a classification target with a slightly smoothed one: with $K$ classes and true class $c$, the target is $q_c = 1 - \varepsilon + \varepsilon / K$, and $q_i = \varepsilon / K$ for every other class. The [[cross-entropy]] is computed against this target instead of the one-hot distribution. A one-hot target pushes the probability of the true class toward $1$ and drives the inputs of [[softmax]] infinitely far apart; the smoothed target attains its optimum at finite values, so the model does not become overconfident.

Example: With $K = 4$, $\varepsilon = 0.1$ and the first class true, the target distribution is $(0.925, 0.025, 0.025, 0.025)$. The original [[Transformer]] takes $\varepsilon = 0.1$.
