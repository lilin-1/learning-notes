An [[attention mechanism]] that scores with $\phi(q)^{\top}\phi(k)$ instead of the $\exp(q^{\top} k)$ of [[softmax]], where $\phi$ is a feature map, often $\phi(x) = \mathrm{elu}(x) + 1$ to keep the scores positive. Associativity of multiplication then applies:

$$o_i = \frac{\phi(q_i)^{\top} S_i}{\phi(q_i)^{\top} z_i}, \quad S_i = \sum_{j \le i} \phi(k_j)\, v_j^{\top}, \quad z_i = \sum_{j \le i} \phi(k_j),$$

and both $S_i$ and $z_i$ can be accumulated position by position.

Note: In generation it therefore behaves like a recurrent network: each step updates a $d_k \times d_k$ state $S$ without storing the keys and values of the whole history, and neither computation nor memory per token grows with the length. The price is expressiveness: a state of fixed size must summarize the entire history, and recalling one distant token exactly is harder than with softmax attention.

Example: With $d_k = 128$, the state $S$ holds $128 \times 128 = 16384$ numbers regardless of the context length. The same head with softmax attention caches $2 \times 128 \times 10^5 \approx 2.6 \times 10^7$ numbers for a context of 100,000.
