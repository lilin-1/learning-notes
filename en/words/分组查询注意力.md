[[multi-head attention|Multi-head attention]] in which several query heads share one set of keys and values, abbreviated GQA: the $h$ query heads are split into $g$ groups, each sharing one key head and one value head. With $g = h$ it is multi-head attention; with $g = 1$ it is called multi-query attention (MQA). The number of key and value heads falls from $h$ to $g$, and the [[KV cache]] shrinks to $g / h$ of its former size.

Note: What is reduced is the key–value heads, not the query heads. The $h / g$ query heads of a group keep their own projections and assign different attention weights over the same keys; only the values they gather are shared. The ability to decide which positions to attend to is therefore largely retained, and what is lost is the diversity of values. The memory and bandwidth saved can buy longer contexts or larger batches; a smaller $g$ saves more and loses more expressiveness, with MQA as the extreme.

Example: Llama 2 70B has 64 query heads and 8 groups of keys and values, each group shared by 8 query heads, so its KV cache is $1/8$ that of multi-head attention.
