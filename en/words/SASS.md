The machine instructions that NVIDIA [[graphics processing unit|GPUs]] execute, assembled from [[PTX]], with a different encoding for each architecture generation. The 32 threads of a [[warp]] execute each instruction together. Common arithmetic instructions are `FFMA` (single-precision fused multiply–add), `IMAD` (integer multiply–add) and `HMMA` (matrix multiply–accumulate on the [[Tensor Core|Tensor Cores]]). Common memory and synchronization instructions are `LDG` and `STG` (load from and store to GPU memory), `LDS` and `STS` (load from and store to shared memory), `BAR` (barrier within a thread block) and `SHFL` (register exchange within a warp).

Note: A GPU does not execute out of order as a CPU does: the instructions of a warp issue in program order, and when the data an instruction needs has not arrived, the scheduler switches to another warp. Latency is therefore hidden by switching between warps, and the compiler orders instructions on that assumption. NVIDIA publishes the names and meanings of the opcodes but not their encoding, so SASS is not normally written by hand, only inspected with `cuobjdump -sass`.

Example: The single-precision multiply–add `FFMA R0, R2, R3, R0` computes $r_0 \leftarrow r_2 r_3 + r_0$ once for each of 32 threads. Each A100 partition has only 16 single-precision units, so this instruction takes two cycles to complete.
