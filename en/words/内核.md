A function executed on a [[graphics processing unit|GPU]]. The CPU issues one launch command, and the GPU runs the function on thousands of threads at once, each thread using its own index to process one piece of data. A launch must state how the threads are organized: how many thread blocks, how many threads per block, and how much shared memory each block uses. The kernel's machine code is loaded into GPU memory by the driver in advance, and the launch command carries only its address and the arguments.

Note: Because blocks do not depend on one another, the same kernel runs on GPUs of any size: a small GPU executes it in several rounds, a large one in a single round, with the same result. Each operation of a [[neural network]], such as a matrix multiplication or a softmax, is usually carried out by one or a few kernels. Every launch has a fixed overhead of a few microseconds, which matters when kernels are short.

Example: To add two vectors of length $2^{20}$ elementwise, one can launch 4096 blocks of 256 threads. Counting from 0, thread $t$ of block $b$ computes $z_i = x_i + y_i$ with $i = 256b + t$; thread 5 of block 3 handles $i = 773$.
