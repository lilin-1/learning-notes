The ratio of the number of operations in a computation to the bytes it reads from and writes to [[memory hierarchy|GPU memory]], measured in operations per byte. Dividing the peak compute of a [[graphics processing unit|GPU]] by its memory bandwidth gives a critical value. Below it, the arithmetic units wait for data and the running time is set by bandwidth, which is called memory-bound; above it, the time is set by compute, which is called compute-bound.

Note: Plotting attainable compute against intensity gives a line that rises linearly up to the critical value and then stays flat, like a roof; this is the roofline model. It points the way to optimization: elementwise operations and [[layer normalization]] have very low intensity and can be sped up only by reading and writing less, whereas large matrix multiplications have high intensity and need faster arithmetic units.

Example: The A100 peaks at 312 TFLOPS for 16-bit matrix multiplication and has a bandwidth of about 2 TB/s, so the critical value is about 156 operations per byte. Multiplying a $d \times d$ matrix of 16-bit weights by a vector reads $2d^2$ bytes and performs $2d^2$ operations, an intensity of 1. When $b$ vectors share that read, the intensity is about $b$.
