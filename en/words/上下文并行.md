A form of parallelism that cuts one long sequence into segments assigned to several GPUs. Each GPU keeps the queries, keys and values of its own segment. For attention, the keys and values are passed around a ring from each GPU to the next. Each GPU computes blockwise with every segment in turn, as [[FlashAttention]] does, merging the results segment by segment, and the passing overlaps with the computation.

Note: Operations such as the feedforward network act on each position independently and need no communication after the split; only attention must see all positions. Spread over $N$ GPUs, the activation memory per GPU therefore falls to $1/N$, and the trainable sequence length grows linearly with the number of GPUs. When segments are long enough, passing one segment's keys and values takes no longer than computing with it, and communication hides entirely behind computation.

Example: One million tokens are spread over 8 GPUs, 125,000 on each. The queries on each GPU are computed against the 8 segments of keys and values in turn; after one trip around the ring, the result is the same as on a single GPU.

Paper: [Ring Attention with Blockwise Transformers for Near-Infinite Context](https://arxiv.org/abs/2310.01889) (Liu et al., 2023)
