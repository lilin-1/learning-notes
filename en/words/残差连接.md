A connection that adds a sublayer's input directly to its output: $y = x + F(x)$, where $F$ is the function the sublayer computes and the input and output have the same dimension. Since $\partial y / \partial x = I + \partial F / \partial x$, [[backpropagation]] can pass gradients straight back to shallow layers through the identity term, so even very deep [[neural network|neural networks]] train effectively.

Note: It also changes what a sublayer has to learn: only a correction to its input, $F(x) = y - x$, rather than the whole mapping. In a deep network many sublayers make small corrections, and signals and gradients travel along the identity path, so the network can be made very deep.

Example: Setting $F \equiv 0$ gives $y = x$. Inserting a residual block into a network therefore never shrinks the set of functions it can represent.

Paper: [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385) (He et al., 2015)
