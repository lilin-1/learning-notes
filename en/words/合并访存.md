A way of accessing memory in which the threads of a [[warp]] access adjacent addresses in GPU memory, so that the hardware merges their requests into a few transfers. GPU memory transfers data in 32-byte sectors, and the unused bytes of a sector are read anyway. When thread $i$ reads element $i$, a warp's requests fall into a few consecutive sectors; when neighboring threads' addresses are far apart, each thread occupies a sector of its own, and most of what is read is wasted.

Note: The speed of a memory-bound [[kernel]] depends almost entirely on effective bandwidth, and coalescing can make a difference of several times. To read a row-major matrix by columns, a common approach is first to load a tile into [[memory hierarchy|shared memory]] with coalesced reads, then take the columns from there.

Example: Each of the 32 threads in a warp reads 4 bytes. With consecutive addresses that is 128 bytes, exactly 4 sectors, all of it useful. With neighboring threads 512 bytes apart, the 32 threads fall into 32 sectors and $32 \times 32 = 1024$ bytes are transferred, of which only 128 bytes, $1/8$, are useful.
