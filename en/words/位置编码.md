A vector added to the [[embedding]] to mark the position of a [[token]]. [[self-attention|Self-attention]] without a mask is equivariant to permutations of its input and cannot tell order by itself; positional encodings supply the order. The original design uses fixed sinusoids:

$$PE_{(p,\,2i)} = \sin\!\left(\frac{p}{10000^{2i/d}}\right), \quad PE_{(p,\,2i+1)} = \cos\!\left(\frac{p}{10000^{2i/d}}\right),$$

where $p$ is the position and $i$ indexes the dimensions.

Note: With a [[causal mask]] the situation differs. Position $i$ sees only the first $i$ tokens, from which the model can infer the position indirectly, and decoder models with no positional encoding at all still work. But the network has to derive this information itself, which is less direct, so positional encodings remain standard in practice.

Example: For $d = 4$, $PE_p = \big(\sin p, \cos p, \sin(p/100), \cos(p/100)\big)$, so $PE_0 = (0, 1, 0, 1)$ and $PE_1 \approx (0.84, 0.54, 0.01, 1.00)$.
