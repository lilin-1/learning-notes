The time from the arrival of a request to the return of its first output [[token]], abbreviated TTFT. It consists mainly of queueing time and [[prefill and decode|prefill]] time and grows with the length of the prompt; in a chat, it determines how soon the user sees the first word.

Example: If prefill processes 10,000 tokens per second, a 4000-token prompt takes about 0.4 seconds to produce its first token when there is no queue.
