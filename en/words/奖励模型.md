A model that gives a response a scalar score approximating human preference. It is trained on pairwise comparisons: for the same prompt $x$, a person picks the better response $y_w$ and the worse $y_l$ of two. Writing $r(x, y)$ for the model's score of response $y$, the loss is

$$\mathcal{L} = \log\Big(1 + e^{-(r(x, y_w) - r(x, y_l))}\Big).$$

The larger the gap in the right direction, the smaller the loss.

Note: It is usually made from a [[language model]] by removing the layer that outputs the vocabulary and adding a linear layer that outputs one number. The scores have no absolute meaning; only differences do: a gap $\Delta$ passed through the logistic function gives the probability $1 / (1 + e^{-\Delta})$ that the first response wins. A reward model only approximates human preference, and when optimized against too hard, the policy finds responses that win high scores dishonestly, which is called reward hacking.

Example: For two responses with scores 2 and 0, the model judges the first better with probability $1 / (1 + e^{-2}) \approx 0.88$. If the person chose the first, the loss is $\ln(1 + e^{-2}) \approx 0.13$; if the second, $\ln(1 + e^{2}) \approx 2.13$.
