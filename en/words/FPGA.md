A chip that can be reconfigured after manufacture; the name stands for field-programmable gate array. It consists of many lookup tables, multiply–add units and small memory blocks, joined by programmable wiring. The configuration specifies what each lookup table stores and which connections are made; loading one configuration turns the chip into a dedicated circuit, and loading another turns it into a different one. A lookup table stores a truth table and can implement any logic function of its few inputs.

Note: It differs fundamentally from a [[graphics processing unit|GPU]] in executing no instructions: a GPU has general-purpose arithmetic units run a program instruction by instruction, whereas an FPGA lays out the computation itself as a circuit. Its clock runs at only a few hundred MHz, and it wins through massive parallelism in the circuit; bit widths, memory layout and data paths can all be tailored to the model. The price is development in a hardware description language or through high-level synthesis, compilations that often take hours, and peak compute and bandwidth below those of GPUs of the same generation.

Example: A common lookup table has 6 inputs and stores $2^6 = 64$ bits. The product of two 3-bit unsigned numbers is at most $7 \times 7 = 49$ and fits in 6 bits. Each output bit is a function of the 6 input bits, so 6 lookup tables form a 3-bit multiplier without using a dedicated multiply–add unit.
